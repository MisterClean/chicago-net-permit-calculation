# Security

Report suspected security vulnerabilities privately through this repository's **Security → Advisories → Report a vulnerability** page. Use public issues for ordinary bugs and methodology questions; do not post credentials or private data.

The maintained version is the latest commit on `main`. Frozen source data is public evidence, not executable code. Notebook execution runs repository Python code; review changes before running contributed notebooks.

Offline replay needs no credentials or network access. Live acquisition uses the public endpoints documented in [SOURCES.md](SOURCES.md).
